# Unstuck

A low-fidelity writing workspace with an interactive timeline, an infinite idea board, and sample plot holes you can resolve on the story map.

## Run locally

```sh
git clone https://github.com/aellanguyen/unstuck.git
cd unstuck
```

Open [writer-desktop.html](writer-desktop.html) or [writer-phone.html](writer-phone.html) in a browser. Both files work without a build or server.

Open **The Last Train** and select a red plot-hole node. Under **Suggestions**, choose **Add node** to put a missing beat on the timeline and clear that knot. Analysis and suggestions use sample data. Project edits are stored in the browser.
